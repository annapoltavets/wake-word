# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Scope

This directory is one independent PlatformIO + ESP-IDF project inside the Module_6 coursework repo (sibling directories are unrelated projects with no shared code). Target: `esp32-s3-devkitc-1`, plain C (`.c`, not C++ like the older `M_6_1_*` projects), pinned `espressif32@6.8.1` / `framework-espidf@3.50301.0`.

## Commands

Run from this directory with the PlatformIO CLI:

```bash
pio run                       # build
pio run -t upload -t monitor  # flash, then open serial monitor (115200, exception decoder on)
pio run -t clean
```

No tests or lint tooling exist. `sdkconfig.esp32-s3-devkitc-1` is generated by the build; don't hand-edit it. Persistent config lives in `sdkconfig.defaults` (currently `-O2`-style performance optimization and 240 MHz, for inference speed); defaults only apply when the generated sdkconfig is deleted and regenerated by a build. `src/CMakeLists.txt` globs everything in `src/`, so new files are picked up without registration. After changing a component's `CMakeLists.txt`, delete `.pio/build/*/CMakeCache.txt` and `CMakeFiles` or the change may not be picked up. If `pio` is not on PATH, use `~/.platformio/penv/bin/pio`.

## Architecture

Pipeline of three FreeRTOS tasks: microphone → `audio_task` → `audio_queue` → `inference_task` → mutex-protected LED state (`led_set_state`) → `led_task` (woken by task notification).

- `audio.{c,h}`: I2S RX (INMP441-style mic, 16 kHz, 32-bit slot, left channel) on GPIO 4/5/6 (BCLK/WS/DIN). `audio_task` reads 512-sample (32 ms) frames, converts 32-bit → 16-bit with `>> 16` plus clamping (`>> 14` clipped normal speech), and pushes `audio_frame_t` to `audio_queue` (depth 8, non-blocking send; drops frames with a warning when full).
- `wake_word.{c,h}`: classifier interface. `wake_word_process()` takes a `WW_WINDOW_SAMPLES` (1 s, 16000) window and fills `ww_result_t` (`WW_NONE/ON/OFF/TOGGLE/BLINK` + score vs `WW_THRESHOLD`). With `WW_USE_ENERGY_STUB 0` (current) it calls the Edge Impulse model via `ei_wrapper_classify()` for the label `carlos` (the model's only keyword; the other label is `unknown`) and maps it to `WW_BLINK` (LED blinks twice). `WW_USE_ENERGY_STUB 1` switches back to an RMS-loudness stub that always returns `WW_TOGGLE`.
- `components/edge_impulse/`: ESP-IDF component with the unzipped Edge Impulse C++ library (`edge-impulse-sdk/`, `model-parameters/`, `tflite-model/`, ~28 MB, vendored as exported) plus our C-callable wrapper `ei_wrapper.{h,cpp}`. To update the model, re-export the library from Edge Impulse Studio and replace those three folders; update `WW_KEYWORD_LABEL` in `wake_word.c` if labels change. `src/` pulls it in via `REQUIRES edge_impulse`; `src/` stays plain C, only the component is C++.
- `main.c`: `inference_task` keeps a 1 s sliding window (`memmove` + append each frame), runs inference every `HOP_FRAMES` (4 frames = 128 ms) unless every frame in the window is below `VAD_RMS_MIN` (RMS silence gate, tuned for the `>> 16` scale; override with `-DVAD_RMS_MIN=...`; an event-driven end-of-word trigger was tried and dropped because noise never lets the word end be found), and after a detection skips `COOLDOWN_FRAMES` (31 ≈ 1 s) of inference. Maps labels to `led_cmd_t` and calls `led_set_state()`.
- `led.{c,h}`: the LED level is a static shared variable guarded by a mutex. `led_set_state()` (ON/OFF/TOGGLE, read-modify-write under the mutex; BLINK sets a pending flag) then notifies `led_task`, which reads the level/flag under the mutex and drives GPIO 15. BLINK flashes `LED_BLINK_COUNT` times (`LED_BLINK_MS` on/off) in `led_task`, then restores the stored level. There is no LED queue.

Task placement is deliberate: `audio_task` (prio 6) and `led_task` (prio 4) are pinned to core 1; the heavy `inference_task` (prio 5, 16 KB stack for the DSP + inference) is pinned to core 0 so inference never starves I2S reads. Keep that split when adding work.

## Gotchas

- The frame size/hop/cooldown constants in `main.c` assume 512-sample frames at 16 kHz (`AUDIO_FRAME_SAMPLES`, `AUDIO_SAMPLE_RATE` in `audio.h`); change them together, and keep `WW_WINDOW_SAMPLES` matching the model's expected input.
- `audio_queue` and the LED mutex are created in `audio_init()` / `led_init()`; both must run in `app_main` before the tasks are created.
- `platformio.ini` sets 16 MB flash and octal PSRAM, but `board_build.extra_flags` is not a standard PlatformIO option for ESP-IDF, so the PSRAM define may not take effect. PSRAM is controlled through sdkconfig, so check there before relying on it (e.g. for a tensor arena).
- Comments are mostly Ukrainian; match the language of the surrounding file. Code uses tab indentation and Allman braces.
